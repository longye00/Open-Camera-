# Open Camera 名单版 2（测试版）

基于 Open Camera 1.56.2 的源码补丁。**本次更新：一个编号可拍多张、任意选择编号、默认手动切换、水平辅助默认关闭并改为细线。**

这是源码与构建工作流，不是已经编译好的 APK。v2 的逻辑测试已通过，仍需 GitHub Actions 编译和手机验收。本更新针对 Open Camera 名单版，不是另一个 Flutter「list photo」应用。

## 拍照方式

1. 初次使用，在取景界面点「导入拍摄编号」，或进入设置 →「编号拍摄 / 名称列表」。
2. 一行一个编号，从 Excel 复制一列粘贴即可；不要表头。保存后启用编号拍摄。
3. 取景界面的小型编号栏显示当前编号和本版已确认的拍摄张数。
4. **点击中间编号**打开可搜索的名单，点击任意一行选择；左右箭头手动切换上一个、下一个。
5. **默认拍完仍停留当前编号**。可以多次单击快门为同一编号拍不同角度。
6. 文件名为 `编号_001.jpg`、`编号_002.jpg`、`编号_003.jpg`…，序号至少三位。
7. 回到拍过的编号会接着编号，不会重新从 001 开始。重新打开应用也保留所选编号和计数。
8. 长按取景界面的编号可打开管理；「拍完自动切换编号」为可选项，**默认关闭**。开启后只在确认保存成功时切换，到末尾停留最后一个编号。

### 输入与保存边界

- 每批最多 5,000 个编号；编号仍需符合文件名规则，不可重复（不区分大小写）。
- 同一编号可拍多张，但仍只支持**普通 JPG、逐次单击快门**；不支持 RAW、HDR/DRO、长按连拍、系统重复拍摄、SAF 保存目录。
- 拍照或保存中禁止修改编号，避免照片被分到错误编号。
- 更新名单保留相同编号的计数；移除后重新导入同名编号也保留已用序号。不会删除原图。
- 对保存目录内可检查到的同名编号文件，自动选取更大的序号。保存时另外保留防覆盖检查；若发生竞争冲突或无法核实实际文件名，则停止并要求确认，不强行覆盖。
- 保存异常或中断时，不自动增加成功数量；在编号栏/管理中核对上一张。已尝试的序号不重复使用，所以失败后可能出现序号空缺。
- 计数是本版确认保存的记录，并非实时相册文件数量；删除或手动移动文件不会回退计数。
- 相片仍由 Open Camera 原来的保存流程写入，实际目录以应用「保存位置」设置为准；常见默认目录为 `DCIM/OpenCamera`。

## 水平辅助

- **首次启动默认关闭**，不注册本功能的传感器监听。
- 设置 →「水平辅助（细线）」手动开启；之后记住用户选择。
- 主线从旧版 2.5 dp 改为约 1 dp；减弱暗色描边，缩短水平线，缩小俯拍十字。
- 删除取景画面中的「保持水平 / 已对齐」文字框，只保留细线或小十字；对齐后变黄。
- 仅改变预览辅助线，不把图形写进照片，不自动旋转或裁切。
- 原版 Open Camera 自己的角度线、网格与此开关独立；若同时启用可能重复显示，请按需要关闭原有辅助线。

## 安装与旧版数据

v2 使用独立测试应用标识，安装后的名称是 **Open Camera 名单版 2**。这是为了避免 GitHub 临时调试签名不同而迫使卸载现有版本。

- 不用卸载旧名单版；两版设计为并存，实际安装仍待手机确认。
- v2 不读取旧版私有设置，**需要重新粘贴编号名单**，旧版拍摄计数不会自动迁移。
- 不会主动删除旧版照片。先保留旧应用和已拍照片，验证新版本后再考虑整理。
- 这是调试签名构建。以后若要持续原位升级 v2，需要配置并妥善保存固定签名密钥；不要把私钥提交到公共仓库。

## 构建

更新方法见 [UPGRADE-v2.md](UPGRADE-v2.md)。继续使用仓库已有的「Build Open Camera Name Queue」工作流，**新建一次 main 分支的运行**。

成功后下载 `OpenCamera-NameQueue-v2-test-build` 构建产物，包含 APK、对应完整源码、许可证和 APK 校验值。不要重跑旧提交来测试新代码。

本地可运行：

```sh
python3 tools/test_local.py
```

测试包含解析、任意编号选择、默认手动多拍、进程重启状态、失败恢复、1000 次同编号连续状态提交、版本识别和补丁钩子检查。合成源码样例测试不等同于真实 Android 编译或相机测试。详情见 `docs/v2-verification.txt`。

## 手机验收

用临时编号 A、B、C，先做小范围测试：

- A 连续单击拍 3 张，应仍选中 A，文件名分别是 A_001.jpg、A_002.jpg、A_003.jpg。
- 直接选择 C 拍一张，再选回 A，应继续保存为 A_004.jpg。
- 退出重开，确认仍选择 A，下一张继续递增。
- 搜索编号能筛选；输入不存在的编号会显示空结果提示。
- 默认无水平线；手动开启后检查细线、俯拍小十字及横竖屏方向。
- 检查编号栏是否遮挡你手机上的原有相机按钮。不同屏幕、字体大小和旋转方向需要实际验收。
- 检查保存位置、实际文件名和照片完整性；确认辅助线没有出现在原图中。

`docs/v2-ui-preview.html` 是交互布局示意，不是 APK 实机截图。旧 `docs/` 中未带 v2 标记的示意与早期说明仅记录 v1。
