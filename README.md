# Open Camera：名称队列 + 水平辅助

针对 **Open Camera 1.56.2（版本号 96，Android 6.0 及以上）** 编写。这里无法联网下载 Android 构建工具，也未取得完整上游源码用于实际合并，因此不声称已完成 Android 编译、安装、相机实拍或传感器实机测试。原始 APK 没有被改动。

## 两个功能

### 1. 提前制作照片名称列表

设计入口：**设置 → 照片名称队列 → 编辑 / 粘贴名称列表**。

从 Excel 复制一列名称，或者从 TXT 复制多行文字；一行一个名称，不要表头。例如：

```text
材料A
材料B
材料C
```

普通单张 JPG 拍照时，计划依次保存为：

```text
材料A.jpg
材料B.jpg
材料C.jpg
```

- 自动补 `.jpg`，输入已有 `.jpg` / `.jpeg` 后缀也可以。
- 成功保存并确认文件名后才推进进度；生成文件名、按快门本身不会消耗一个名称。
- 普通保存失败、应用被杀掉、进度无法持久化或无法确认最终文件名时，保留“待确认”标记，要求检查相册后再继续，避免静默漏号。
- 名单可暂停并保留进度；同一名单再次保存不会重置进度；替换名单会弹出确认。
- 拍完名单后停止名单拍照，不偷偷改回时间戳命名。暂停名单后才恢复普通拍照。
- 支持指定下一张的序号。该操作不会删除照片；回到一个已使用名称时仍会拦截重名。
- 重复名称、非法字符、多列 Excel 的制表符、过长名称会提示具体行号。
- 每批最多 5,000 项，单个名称最多 180 个 UTF-8 字节。
- 重名时停止，不覆盖现有照片，也不自动给名称加后缀。MediaStore 最终名称若被系统改动，则停止自动推进并要求人工核对。
- 当前/下一张名称通过原生提示和设置内的进度页面显示；**本补丁没有增加常驻的名称悬浮条**。

**首版范围**：普通单张 JPG、普通保存目录（包括 Android MediaStore）。暂不支持 RAW、HDR/DRO、多帧模式、长按连拍、重复拍摄及 SAF 保存目录。名单开启时暂时关闭拍后暂停预览，以免删除照片后进度仍前进。录像和其他应用调起的拍照请求不使用名单。

**注意**：此实现对名单照片使用同步保存，速度可能比后台连拍慢，这是为了保证“这一张对应这一个名称”。失败时可能有同名空文件，核对后需要用文件管理器手动删除空文件或换目录；补丁不会擅自删除文件。

### 2. 水平辅助

设计入口：**设置 → 水平辅助（iPhone 风格）**，默认开启，和名称队列独立。

- 平拍：中间水平参考线；手机倾斜时中间线和两侧参考线不对齐。
- 对齐后：参考线合拢并变黄，显示“已对齐”。
- 俯拍或仰拍、手机接近平放时：自动切换为两个十字，重合时变黄。
- 对齐阈值约 1°，持续约 350 毫秒才变黄；超过 1.6°才退出对齐状态，降低抖动导致的闪烁。
- 优先使用重力传感器，无重力传感器时使用加速度计并进行低通平滑；没有传感器或数据过期时不显示虚假的“已对齐”。
- 传感器在相机进入后台时注销，不添加网络或新的敏感权限。
- **这是取景对齐提示，不是照片自动矫正。不会因为这个辅助功能而旋转、裁剪、拉伸照片，也不会把参考线或十字画进照片。**
- 不提供光学畸变校正或透视校正。它是拍摄辅助，不是精密测量仪器。

如果你指的是“拍完自动把照片转正”，Open Camera 原有的自动水平功能属于另一种功能，可能裁剪边缘，本补丁没有默认打开它。为了保留科研照片的原始视野，建议先用水平辅助对齐再拍；原软件中已开启的自动水平设置需自行确认。

`docs/level-preview.html` 是水平辅助的静态界面示意，**不是实际 APK 截图或可调用手机相机的软件**。若原软件原有的角度参考线也开启，建议关闭旧的参考线，避免与新辅助线重复显示。

## 文件说明

- `src/.../PhotoNameQueueCore.java`：名单校验及事务状态。
- `src/.../PhotoNameQueue.java`：原生名单设置、命名、持久化、保存检查。
- `src/.../LevelGuideCore.java`：姿态数学、阈值、稳定时间及迟滞。
- `src/.../AppleLevelGuide.java`：传感器生命周期、水平线/十字绘制及开关。
- `tools/apply_patch.py`：针对 1.56.2 的源码插入与独立安装标识设置。
- `tools/test_local.py`、`tests/CoreTests.java`：可独立执行的逻辑测试与补丁匹配测试。
- `.github/workflows/build-namequeue.yml`：在线自动构建尝试。
- `examples/照片名称示例.txt`：可复制的名称示例。
- `docs/level-preview.html`：水平辅助静态示意。
